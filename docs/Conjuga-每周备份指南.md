# Conjuga 每周备份指南

> 目标：每周花 3 分钟，保证动词库、错题进度、笔记永不丢失。
> 适用于：平板（主力机）→ 网盘（保命符）→ 其他设备（临时查看）。

---

## 一、为什么必须备份

你的全部数据（动词、标签、错题、复习进度、笔记）都保存在**这台设备的浏览器数据库**里，不上传任何服务器。这意味着：

- ✅ 关浏览器、重启平板、断网——数据都在
- ❌ 清理浏览器缓存/清理大师类 App 误删站点数据——**全部消失，无法找回**

> 数据一旦清掉没有任何恢复渠道，备份是唯一的保命符。

---

## 二、每周固定动作（周日 · 3 分钟）

### 第 1 步：导出（主力机上）
1. 打开 Conjuga → 左侧菜单 → **设置**
2. 点 **⬇ 导出备份（JSON）**
3. 文件自动下载，名字形如 `conjuga-backup-20260830.json`
4. 成功提示会显示当前数量：动词 / 标签 / 错题卡 / 笔记——**记一眼这个数字**，和上周对比，确认没有异常（比如动词从 80 变成 3，说明出问题了）

### 第 2 步：上传到网盘
把下载的文件存到你的网盘（坚果云 / OneDrive / 百度网盘 / 微信收藏均可）：
- 建议建一个文件夹：`Conjuga备份`
- 文件名已带日期，不用改名，直接丢进去
- **不要删上周的旧备份**——留最近 4 份，万一最新一份是坏的你还有退路

### 第 3 步：确认（打开网盘看一眼文件在不在，30 秒）
到此结束。

---

## 三、什么时候恢复（导入）

| 场景 | 操作 |
|---|---|
| 平板缓存被清 / 换新平板 / 换浏览器 | 装好 Conjuga → 设置 → **⬆ 导入备份** → 选网盘里的最新 JSON |
| 想在手机/电脑上临时查看数据 | 主力机导出 → 文件传到那台设备 → 导入（**只是快照，看完回主力机继续用**） |

**导入注意**：
- 导入是**合并覆盖**：同一条数据以备份为准，不会删除现有数据
- 导入完成会显示**备份时间**——确认导入的是你想要的那份，别拿两周前的旧备份盖掉新进度
- 导入后错题的复习排期（艾宾浩斯梯度）会一并恢复，继续接着算

---

## 四、跨设备使用规则（方案 2 · 主从纪律）

1. **主力机**（建议平板）：录入动词、练习、复习，一切学习活动只在这里
2. **其他设备**：只读查看——导入快照看完就走，**不要在上面练习**（两边同时产生错题记录，进度会分叉，合并时以谁为准就成了糊涂账）
3. 万一两边都改了：以数据多、进度新的一边为准，导出覆盖另一边，然后立刻回到"只在主力机用"的纪律

---

## 五、每周检查清单（打勾用）

- [ ] 设置页导出了本周备份 JSON
- [ ] 文件已上传网盘 `Conjuga备份` 文件夹
- [ ] 网盘里能看到文件（确认上传成功）
- [ ] 数据量与上周对比无异常（动词/错题数量级合理）
- [ ] 网盘留有最近 4 周的备份，没有误删

## 六、常见问题

**Q：备份文件多大？**
很小。100 个动词 + 全部错题 + 笔记 ≈ 几十 KB，网盘不占空间。

**Q：忘了备份，缓存刚好被清了怎么办？**
没有补救。这就是为什么固定周日做——建议给平板设一个每周日提醒（闹钟标题写"Conjuga 备份"）。

**Q：换手机号/微信会影响备份吗？**
不会。备份是普通文件，和任何账号无关，只要文件在就能恢复。

**Q：以后有云同步吗？**
两周后评估。如果你发现自己频繁在两台设备间倒数据且很麻烦，再考虑加账号同步；如果备份纪律够用，就保持现状——单机 + 备份反而是最稳的方案。
