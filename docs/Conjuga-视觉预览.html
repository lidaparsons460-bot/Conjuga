我的规律笔记 · 共 24 篇

两类笔记：一类挂在具体动词上，一类是独立规律/口诀

e→ie 类变位规律总结8/28 记

e→ie 变化出现在词根重音上。querer / pensar / perder / sentir / preferir 都是这条规律。关键点：nosotros/vosotros 永远不变，因为重音落词尾不落在词根上。配合"横比 o→ue"看，两种 stem 规律共通点就是这两列不换。

规律总结Stem-changing
📌 poder 的特殊之处 （挂于 poder）8/26

现在时 o→ue。Pretérito 完全换词根 pude/pudiste/pudo…这组必须单独背，没有规律可推。Imperfecto 完全规则 podía/podías…——因为它"有规律所以我反而常错当成换词根"，注意切换心态。

动词笔记常错
🎯 Pretérito vs Imperfecto 口诀8/20 记

故事背景 = Imperfecto（我当时在哪儿/我是谁/持续状态）。发生了什么事 = Pretérito（我做了一个动作，然后下一个）。记关键词就看：有 ayer/anoche/el año pasado + 明确时间点 = 肯定 pretérito。有 siempre/de niño/cuando era pequeño + 习惯性/背景 = imperfecto。

口诀时态辨析
car/gar/zar 拼写规律记忆法8/15 记

一句话：C→QU、G→GU、Z→C，都只在 yo 形式（él 形式同）。buscar→busqué、jugar→jugué、lanzar→lancé。原因：保持发音不变，硬腭辅音遇到 e/i 不软化。nosotros/vosotros 不变因为后面是 a（buscamos/jugamos）。

规律速查 · 忘了立刻翻

常规词尾 / 拼写变体 / Stem-changing / Subjuntivo 构成…

① 现在时 Indicativo · 常规词尾

-ar 类-o / -as / -a / -amos / -áis / -an
-er 类-o / -es / -e / -emos / -éis / -en
-ir 类-o / -es / -e / -imos / -ís / -en
⭐ 记忆法对比 -ar 和 -er：1/2/3 单一致 a↔e，nosotros/vosotros 也是 a↔e，6 人称复数 an↔en。-ir 夹中间，单数和 -er 同复数和 -ir 自己同。

② 拼写变体（c→qu / g→gu / z→c）

-car (yo)buscar → busqué（pretérito）c→qu 保持硬腭音
-gar (yo)jugar → jugué g→gu 保持硬腭音
-zar (yo)lanzar → lancé z→c（西班牙语 ze/zi 用 ce/ci 拼写）
🔑 关键只在 e 前变。-emos/-áis 后面是 a，所以我们/你们不变（buscamos / jugáis）。

③ Stem-changing：e→ie / o→ue / e→i

触发条件重音落在词根时变；nosotros / vosotros 永远不变（重音落词尾）。这是铁律!
e → iequerer / pensar / perder / sentir / cerrar / preferir
o → uepoder / dormir / volver / contar / costar / probar
e → i （只 -ir 类）pedir / servir / repetir / medir / vestir

④ 未来时 Futuro Simple 构成（超简单!）

规则整个动词（不去任何词尾）+ -é / -ás / -á / -emos / -éis / -án
-ar 例hablar → hablaré / hablarás / hablará / hablaremos / hablaréis / hablarán
-er 例comer → comeré / comerás / comerá / comeremos / comeréis / comerán
💡 坑不规则少数字完全换词根：hablar→habr-（habré）、tener→tendr-、poder→podr-、querer→querr-、saber→sabr-…

⑤ 虚拟式现在时 Subjuntivo Presente 构成口诀

两步走① 先变成 yo 现在时（hablo / como / vivo）② 换反向元音尾：-ar 类 → e/-es/-e/-emos/-éis/-en；-er/-ir 类 → a/-as/-a/-amos/-áis/-an
-ar 例 · hablaryo hablo → hable / hables / hable / hablemos / habléis / hablen
-er 例 · comeryo como → coma / comas / coma / comamos / comáis / coman
🌟 辅助记忆"把陈述式的 a 换成 e，e 换成 a"——ar 类大换阵营到 e 这边，er/ir 类大换阵营到 a 这边。
