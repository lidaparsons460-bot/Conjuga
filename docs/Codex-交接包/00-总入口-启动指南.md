## 一、30 秒启动这个网站

```bash
cd conjuga-app
npm install
npm run dev
# 打开 http://localhost:5173
```

- 技术栈：**Vue 3 + Vite 8 + vue-router（hash 模式）+ Dexie(IndexedDB) + verbos(西语动词变位数据库包)**
- 依赖仅 4 个（见 `conjuga-app/package.json`），无 Pinia、无 UI 框架、无 CSS 框架——状态全部用 composables 的 `reactive` 手写
- 构建：`npm run build` → `dist/`（约 2.6MB，其中 verbos 词库数据占 2.4MB，是独立异步 chunk）
- `vite.config.js` 已配置 `server.host: true`（IPv4/IPv6/局域网全监听——曾因只绑 IPv6 导致 localhost 打不开）

**环境备注（原开发机）**：Node 装在 `D:\node.js\install` 且未加入系统 PATH。换机器无此问题。

## 四、给 Codex 的启动 Prompt（复制即用）

```
你接手的是一个已上线运行的西语动词变位学习 PWA「Conjuga」。
项目根目录下有「Codex-交接包」，先读 00-总入口 和 01-技术真相与红线，再动代码。
技术栈 Vue3 + Vite + vue-router(hash) + Dexie + verbos，无 UI 框架，样式全走三层令牌。
启动方式：cd conjuga-app && npm install && npm run dev。
改动约束：
1) 颜色/字号/间距只允许引用 tokens.css 令牌，禁止硬编码 hex/px；
2) 超级矩阵必须保持单表 sticky 结构，禁止拆双表同步列宽；
3) 动词字段名是 infinitive、错题字段名是 infinitivo（历史遗留，两者都在用），新代码遵循 01 号文件第 2 节的命名表；
4) verbos 包人称键无重音（tu/ud/uds），imperativo 是顶层 afirmativo/negativo 且只有 4 人称；
5) 改完必须 npm run build 验证，涉及数据流转必须构造真实数据走通链路，"编译过"不算验证。
我的任务是：<在这里写你的具体需求>
```

## 五、验证标准（沿用本项目的验收纪律）

1. `npm run build` 通过
2. 浏览器实际加载页面、控制台零报错（不是只看 HTTP 200）
